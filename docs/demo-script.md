# 《舆图山河录·三重疆域》30 秒课堂演示脚本

> 用途：华为 ICT 创新赛现场快速演示，覆盖**开场 → 地图联动 → 四档可信回应 → 多轮追问 → 气泡跟随**。
> 前置：后端 `npm run serve`（3001）、前端已构建；浏览器打开 `http://localhost:3001/map`。
> 所有问法均已实测可稳定触发对应分级；事实只来自召回材料，模型仅润色、不产出事实。

| 时间 | 操作 | 输入 / 动作 | 预期效果（可信等级） |
|---|---|---|---|
| 0:00–0:03 | 开场 | 点击左下角**卷轴宠物** | 宠物右侧弹出多轮对话气泡，输入框就绪 |
| 0:03–0:09 | 直答 + 地图联动 | 问：`唐朝最西到哪？` | **L1 直答**：西至碎叶镇，挂《旧唐书》《新唐书》出处；点气泡内「地图定位」，地图聚焦碎叶（行政层） |
| 0:09–0:14 | 条件答 | 问：`唐朝面积多少？` | **L2 条件答**：同题存在直辖 944 万 / 含羁縻 1237 万两口径，提示「存在多种口径，请注意区分」 |
| 0:14–0:19 | 证据展示 | 问：`明朝为什么不画北界？` | **L4 证据展示**：北面为蒙古诸部、无稳定边界，列出《明史·鞑靼/瓦剌传》证据，不画闭合边界 |
| 0:19–0:23 | 范围声明 | 问：`宋朝疆域有多大？` | **L3 范围声明**：库内未收录宋代，如实说明超出收录范围，不编造 |
| 0:23–0:27 | 多轮追问（指代消解） | 承接上一轮继续问：`那它东边呢？` | 检索前结合上文把「它」改写为对应朝代再召回；材料不足时同样如实声明，不被上下文带偏 |
| 0:27–0:30 | 气泡跟随 | 按住宠物拖动到屏幕右侧 | 气泡实时跟随宠物移动；右侧空间不足时自动翻到宠物左侧，全程不遮挡地图主体 |

## 四档分级速查（现场答疑备用）

| 等级 | 名称 | 触发条件 | 演示问法 |
|---|---|---|---|
| 1 | 直答 | 单一口径、有直接史料 | 唐朝最西到哪？ |
| 2 | 条件答 | 同题多种管辖口径、分数并列 | 唐朝面积多少？ |
| 3 | 范围声明 | 超出收录范围 / 无足够史料 | 宋朝疆域有多大？ |
| 4 | 证据展示 | 学界无定论、只列证据不画边界 | 明朝为什么不画北界？ |
